# 手取り年収シミュレーター MVP

額面年収・就業形態・扶養人数を入力するだけで、社会保険料・所得税・住民税を差し引いた手取り額の目安を計算するWebアプリ。HAKONIWA LAB([[subsidy-checker]]・[[sidejob-checker]]・[[career-checker]]・[[insurance-checker]]と同じデザインシステム)の5本目のツール。ビルドツール不要のVanilla HTML/CSS/JS。

他4本は「5問診断→タグベースでマッチング」というクイズ型アーキテクチャだったが、本アプリは**フォーム入力→計算式で算出**という別の構造。A8.netの審査結果を待たずに着手できるテーマとして企画した(既存4アプリはアフィリエイト案件の承認待ちが多い状況だったため)。

## ローカルでの動作確認

```
cd takehome-calculator
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。`index.html` を直接ダブルクリックしても動作する(外部通信は一切行わない)。

## ファイル構成

```
takehome-calculator/
├─ index.html          … 入力フォーム+結果表示のSPA本体
├─ css/style.css        … 他4アプリと同じCSS変数デザインシステム(コピー)+フォーム/結果表示用スタイルを追加
└─ js/
    ├─ calculate.js       … 手取り額の計算ロジック(純粋関数、DOM非依存)
    └─ app.js             … フォームの入力受付・DOM描画
```

## 計算ロジックについて

`js/calculate.js`に会社員(`calcEmployee`)・自営業/フリーランス(`calcSelfEmployed`)それぞれの概算計算を実装。

- **給与所得控除**: 令和2年分以降の速算表をそのまま実装。
- **社会保険料(会社員)**: 健康保険料(協会けんぽ全国平均目安 4.99%)・厚生年金保険料(全国一律 9.15%)・雇用保険料(0.6%)を年収に定率適用する簡易計算。本来は標準報酬月額表の等級で決まるため、月収がボーナス比率等によって等級の境目にある場合は実額とズレる。40〜64歳は介護保険料0.8%を追加。
- **国民年金・国民健康保険料(自営業)**: 国民年金は定額(年204,000円目安)。国民健康保険料は自治体差が非常に大きいため、事業所得の10%を目安とし、年間上限106万円でキャップする粗い近似。
- **所得税**: 2024年分の超過累進税率表+復興特別所得税2.1%上乗せ。基礎控除48万円+扶養控除38万円/人。
- **住民税**: 所得割10%+均等割5,000円の目安。基礎控除43万円+扶養控除33万円/人。実際は自治体により均等割が若干異なる(4,000〜6,000円程度)。

### 検証(2026-08-01)

会社員・独身・扶養0人・40歳未満のケースで、一般に引用される手取り目安と照合済み:

| 額面年収 | 本アプリの算出 | 手取り率 |
|---|---|---|
| 300万円 | 238万円 | 79.4% |
| 400万円 | 315万円 | 78.6% |
| 500万円 | 388万円 | 77.6% |
| 600万円 | 460万円 | 76.7% |
| 800万円 | 590万円 | 73.7% |
| 1000万円 | 710万円 | 71.0% |

一般的な手取り目安表とおおむね一致(1000万円のケースでやや保守的な数字になる傾向)。自営業側は経費率次第で結果が大きく変わるため、参考値としての位置づけが強い。

**注意**: あくまで一般的な税率・保険料率に基づく概算であり、正確な金額を保証するものではない。加入する健康保険組合・居住する自治体・年度・各種控除の適用状況によって実際の金額は変わる。年度が変わったら税率表・保険料率(特に協会けんぽの都道府県別料率・雇用保険料率)を再確認すること。

## マネタイズ導線

本アプリはクイズ型の他4アプリと違い、計算して終わり・離脱が早いタイプのツールのため、商品紹介よりも表示広告(Google AdSense等)との相性を優先する方針(2026-08-01)。

- **表示広告**: 結果画面下部の`#ad-slot-result-bottom`(広告プレースホルダ)にAdSenseコードを差し込む想定。AdSense未承認のため2026-08-01時点では空のまま。承認が下りたら広告コードを埋め込む。誤クリック誘発を避けるため、フォーム操作の邪魔にならない結果画面下の1箇所のみに絞っている。
- **他アプリへの送客(クロスリンク)**: 計算結果画面に、`employment_type`に応じたクロスリンクバナーを表示する(`js/app.js`の`buildCrossLinkBanners`)。全ケース共通でinsurance-checkerへ、`self_employed`ならsubsidy-checkerへ(自営業は傷病手当金等が薄いため公的制度の確認を促す)、`employee`ならsidejob-checker・career-checkerへ(収入を増やす副業・転職)。
- **メールリード獲得フォーム**: `#lead-form`。2026-08-01にButtondown(アカウント名`hakoniwalab`)と接続済み(実装の詳細はsubsidy-checkerのREADME参照)。家計系コンテンツやKindle本等への送客リストとして活用する想定。
